# Detecção de Celulares em Vídeo com YOLOv8

Este projeto foi desenvolvido para a disciplina de Computer Vision com o objetivo de realizar a detecção de celulares em vídeos utilizando técnicas de visão computacional e aprendizado profundo.

O sistema utiliza o modelo YOLOv8 para identificar aparelhos celulares em imagens e vídeos, desenhando caixas delimitadoras (bounding boxes) ao redor dos objetos detectados.
